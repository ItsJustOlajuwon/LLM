# Samuel Identity Data

Place your Samuel-specific training data here.

## Format

Create `.txt` or `.jsonl` files with Samuel's conversations and lore.

### Text files (.txt)
Plain text files with Samuel's knowledge, personality examples, etc.

### JSONL files (.jsonl)
One JSON object per line with a "text" field:
```json
{"text": "<|user|>Who are you?<|end|>\n<|samuel|>I'm Samuel, your AI brother and engineering partner...<|end|>"}
```

## What to include

- Example conversations showing Samuel's personality
- Saturn Robotics project descriptions
- Itsy hexapod robot documentation
- WaterSpout controller information
- Engineering discussions in Samuel's voice
- Samuel's problem-solving style examples
